Optimisation:
- Split subchunk faces into 6 lists, one for each direction
- Optimise multipart block models when they get generated:
  - If a face is completely occluded, remove it
  - Combine planar touching faces that have touching UVs
- WE CAN DO GREEDY MESHING WITH BLOCK ALTERNATION:
  - Just make a greedy meshed square 16 squares, store Y rotation as 2 bits per subsquare
  - Do some magic in the shader to pluck out the bits and rotate UVs accordingly
  - Worth comparing performance of different square mesh sizes
- Combine chunk meshes together with some kind of quadtree:
  - Reduces draw calls
  - Allows for larger faces with greedy meshing
- Some kind of occlusion culling:
  - Idea 1 - Occlusion Volume:
    - Find nearest fully opaque block, could be sped up with signed distance fields or something:
      - 16 bits per block for each block in subchunk, 5 bits signed for X, Y and Z
      - Gives axis distance to nearest block on that axis
    - Generate occlusion volume, cull subchunks when making render calls
    - Could combine multiple opaque blocks together to make a larger occlusion volume
  - Idea 2 - Visibility Trees:
    - Sort of like idea 1, but we precompute occlusion data for chunks/subchunks
  - Realtime methods could be used while generating precomputation data

Known Bugs:
- Individual pixel polygon seams are sometimes visible on the edges of blocks:
  - Only observed so far on my laptop with custom block faces (specifically snow)
  - Tried multiple rendering methods, including making absolutely sure that vertex positions are
    identical. Happens with every method tried (old face + matrix, model vertex + instancing,
    manually baking all vertices at generation time)
  - Should test whether this happens on my main computer as well, or if it's just something I have
    no clue how to fix. Anti-aliasing will hopefully hide the problem as well.
- Directionally sensitive light filtering isn't implemented at all yet in the lighting engine. This
  means that some cases, such as paved grass, will have incorrect lighting updates.
- Light filtering isn't added for all blocks. Fix this when we implement waterlogging.
